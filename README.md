# Aster

A small, responsive landing page for a fictional team-work platform. It uses plain HTML, CSS, and JavaScript, with no build step or package dependencies.

## Preview

Open `index.html` in a browser, or serve this folder with any static file server.

## Branches

- `main` is the stable landing-page baseline.
- `dev` contains the reviewable contact-request dialog and demo form.

To review the change on GitHub, publish both branches to a GitHub repository and open a pull request from `dev` into `main`.

The contact form is intentionally front-end-only and does not send or store submissions.
